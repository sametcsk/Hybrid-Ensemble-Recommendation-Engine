# Hybrid Ensemble Recommendation Engine
# Hibrit Film Öneri Sistemi

A hybrid recommendation system that combines collaborative filtering and content-based filtering to provide personalized movie recommendations.

Kişiselleştirilmiş film önerileri sunmak için işbirlikçi filtreleme (collaborative filtering) ve içerik tabanlı filtrelemeyi (content-based filtering) birleştiren hibrit bir öneri sistemi.

> **Task / Görev:** Recommendation Systems / Öneri Sistemleri · **Domain / Alan:** Entertainment / Eğlence

## Quick Start / Hızlı Başlangıç

```bash
git clone https://github.com/sametcsk/Hybrid-Ensemble-Recommendation-Engine.git
cd Hybrid-Ensemble-Recommendation-Engine
python -m venv .venv && .venv\Scripts\activate
pip install -r requirements.txt

# Launch Jupyter Notebook / Jupyter Notebook'u başlatın
jupyter notebook notebooks/hybrid-recommender-system.ipynb
```
